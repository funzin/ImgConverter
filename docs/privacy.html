ImgConverter について

ImgConverter は funzin が開発した Chrome と Firefox の拡張機能です。どちらのブラウザでも、ツールバーのクリックで動作します。この拡張機能の単一の目的は、フォーカスしているテキスト欄の Markdown 画像を、保存した幅と高さを使って HTML の img タグに変換することです。Chrome ウェブストアのアイテム ID は pkgimcoeodgcdfnidhgijpopkfhbcomm です。ソースコードは github.com/funzin/ImgConverter で公開しています。このページは、バージョン 0.4.0 の拡張機能の動作を説明しています。

ツールバーのボタンを押したときの動作

ウェブページ上で ImgConverter が動作するのは、ツールバーにあるボタンを押したときだけです。ボタンを押すたびに、現在のタブで次の処理を行います。

  1. 拡張機能は、1 つのスクリプト convert-to-img-tag.js をタブのトップフレームに挿入します。タブの URL もタイトルも読み取りません。
  2. スクリプトは、保存済みの幅と高さを chrome.storage.sync から読み取ります。
  3. スクリプトは、フォーカスしている要素のテキストを読み取ります。その要素に value がない場合は、何も変更せずに終了します。
  4. 入力欄でテキストを選択している場合は、選択部分だけを変換します。選択していない場合は、入力欄全体を変換します。
  5. URL が https: で始まる Markdown 画像を、HTML の img タグに置き換えます。画像はダウンロードしません。
  6. 変換結果を同じ入力欄に書き戻します。

入力欄のテキストはタブの外に出ません

スクリプトは入力欄のテキストをメモリ上に読み込んで変換し、結果を同じ入力欄に書き戻します。テキストをストレージに保存せず、メッセージとして送らず、ネットワークにも送信しません。開発者がこのテキストを受け取ることはありません。

クリック時のこの読み取りは、ウェブサイト内容のローカルな利用です。開発者による収集ではありません。

スクリプトは、フォーカスしている入力欄の種類を確認しません。そのため、パスワード欄にフォーカスがある状態でボタンを押すと、スクリプトはその内容も同じようにローカルで読み取ります。その場合も、内容を保存したり送信したりはしません。

保存するデータは幅と高さだけです

オプションページには、幅と高さの 2 つの入力欄があります。保存すると、拡張機能は入力欄が空の場合も含めて、2 つの値を文字列として chrome.storage.sync に保存します。ボタンを押すたびに、スクリプトは幅と高さを属性として各 img タグに追加します。空の値は追加しません。

両方の値が空の場合、または一度も保存していない場合は、代わりに width=50% を追加します。この既定値はコードの中にあり、拡張機能がストレージに書き込むことはありません。

ブラウザの同期を有効にしている場合、ブラウザがこの 2 つの文字列をユーザーのブラウザアカウントにコピーすることがあります。開発者はこの文字列を受け取りません。ImgConverter には、開発者が運営するサーバーがありません。

権限とリモートコード

ImgConverter が要求する権限は、次の 3 つだけです。

  • activeTab は、ツールバーのボタンを押した後に現在のタブで動作するために使います。
  • storage は、幅と高さを chrome.storage.sync に保存するために使います。
  • scripting は、現在のタブに convert-to-img-tag.js を挿入するために使います。

ホスト権限は要求せず、コンテンツスクリプトも宣言していません。コードはすべて拡張機能のパッケージに含まれており、リモートコードは読み込みません。コンテンツセキュリティポリシーは script-src 'self'; object-src 'self' で、パッケージ内のスクリプトだけを許可します。オプションページが読み込むのは自身のスクリプトだけで、外部のリソースは読み込みません。

開発者はデータを受け取りません

拡張機能のソースコードにはアナリティクスのコードがなく、Cookie も使いません。fetch、XMLHttpRequest、sendBeacon、WebSocket のいずれも呼び出さないため、ネットワークには何も送信しません。開発者はユーザーデータを収集せず、誰にも販売または譲渡しません。

開発者は、次の区分を収集しません。

  • 個人を特定できる情報
  • 健康情報
  • 金融情報と支払い情報
  • 認証情報
  • 個人的な通信
  • 位置情報
  • ウェブ履歴
  • ユーザーの行動

利用の制限

ImgConverter はデータを単一の目的のためだけに使います。承認された用途を除き、ユーザーデータを第三者に販売または譲渡しません。単一の目的と関係のない用途のために、ユーザーデータを使用または譲渡しません。また、信用力の判断または融資の目的で、ユーザーデータを使用または譲渡しません。

保存したサイズを変更または削除する

  • サイズを変更するには、オプションページを開き、幅または高さを書き換えて保存します。
  • 保存したサイズを削除するには、オプションページを開き、両方の入力欄を空にして保存します。両方の値が空の文字列になり、スクリプトは再び width=50% を使います。
  • このブラウザから ImgConverter を削除すると、このブラウザに保存した幅と高さが削除されます。開発者はそのコピーを保持しません。

About ImgConverter

ImgConverter is a Chrome and Firefox extension by funzin. A toolbar click runs it in either browser. Its single purpose is to convert Markdown images in the focused text field into HTML img tags, using the saved width and height. The Chrome Web Store item ID is pkgimcoeodgcdfnidhgijpopkfhbcomm. The source code is public at github.com/funzin/ImgConverter. This page describes how version 0.4.0 of the extension behaves.

What happens when you click the toolbar button

On web pages, ImgConverter runs only when you click its button in the toolbar. Each click runs these steps in the current tab:

  1. The extension injects one script, convert-to-img-tag.js, into the top frame of the tab. It reads neither the URL nor the title of the tab.
  2. The script reads the saved width and height from chrome.storage.sync.
  3. The script reads the text of the focused element. If that element has no value, the script stops and changes nothing.
  4. If you selected text in the field, the script converts only the selection. Otherwise it converts the whole field.
  5. The script replaces each Markdown image whose URL starts with https: with an HTML img tag. It does not download the image.
  6. The script writes the result back into the same field.

Text in the focused field stays in the tab

The script reads the field text into memory, converts it, and writes the result back into the same field. It does not save the text to storage, does not send it in a message, and makes no network request. The developer never receives this text.

The read on the click is local use of website content, and it is not collection by the developer.

The script does not check the type of the focused field. If a password field has focus when you click the button, the script reads that text locally in the same way. It does not store or send that text.

Width and height are the only saved data

The options page has two fields, one for width and one for height. When you save, the extension stores both values as strings in chrome.storage.sync, even when a field is empty. On each click, the script adds the width and the height to each img tag as attributes. It skips a value that is empty.

If both values are empty or were never saved, the script adds width=50% instead. This fallback is part of the code, and the extension never writes it to storage.

If you turn on browser sync, the browser may copy these two strings to your browser account. The developer does not receive them. ImgConverter has no server run by the developer.

Permissions and remote code

ImgConverter requests these three permissions and no others:

  • activeTab, to act on the current tab after you click the toolbar button.
  • storage, to save the width and height in chrome.storage.sync.
  • scripting, to inject convert-to-img-tag.js into the current tab.

It requests no host permissions and declares no content scripts. All of its code ships in the extension package, and it loads no remote code. Its content security policy is script-src 'self'; object-src 'self', which allows only scripts from the package. The options page loads only its own script and no remote assets.

The developer receives no data

The extension source has no analytics code and does not use cookies. It makes no calls to fetch, XMLHttpRequest, sendBeacon, or WebSocket, so it sends nothing over the network. The developer does not collect user data and does not sell or transfer it to anyone.

The developer does not collect these categories:

  • Personally identifiable information
  • Health information
  • Financial and payment information
  • Authentication information
  • Personal communications
  • Location
  • Web history
  • User activity

Limited use

ImgConverter uses data only for its single purpose. It does not sell or transfer user data to third parties, outside of the approved use cases. It does not use or transfer user data for purposes unrelated to its single purpose. ImgConverter also does not use or transfer user data to determine creditworthiness or for lending purposes.

Change or delete the saved size

  • To change the size, open the options page, edit the width or the height, and save.
  • To delete the saved size, open the options page, clear both fields, and save. Both values become empty strings, and the script goes back to width=50%.
  • Removing ImgConverter from this browser removes the saved width and height from this browser. The developer holds no copy.
